隐私政策

生效日期：2026-09-28

我们收集什么

Nocturne 的核心单人试玩不要求注册，也不主动请求相机、麦克风、通讯录、定位或短信权限。应用会在本设备保存语言偏好、访客显示名称、剧本完成记录和匿名访客标识，用于恢复你的界面和房间体验。

多人房间数据

当你创建或加入房间时，匿名访客标识、显示名称、语言、房间成员关系以及你主动产生的游戏阶段、搜证、质询和投票事件会发送到 Nocturne 服务端，用于同步同一房间的游戏进度。剧本内容不会因为删除访客资料而被删除。

服务商与地区判断

生产服务托管在 Vercel，房间和剧本数据存储在 Neon PostgreSQL。首次打开时，应用可读取部署边缘提供的国家/地区代码，用于中国大陆默认中文、其他地区默认英文；不会把访客 IP 主动发送给第三方地理定位服务。当前版本不包含广告和行为分析 SDK。

你的选择与删除

你可以在应用内打开个人资料面板修改显示名称，或使用“删除访客资料”删除本设备的本地记录，并请求服务端删除对应的访客资料、成员记录和游戏事件关联；该操作会关闭你创建的未结束房间。若设备无法联网，本地资料仍会先被清除。

联系信息

正式商店提交前，发布方必须在此处补充真实运营主体、客服邮箱、数据保存期限和适用法律信息。当前项目反馈入口为 GitHub Issues。

Privacy policy

Effective date: 2026-09-28

What we collect

Nocturne's core solo trial does not require registration and does not request camera, microphone, contacts, location or SMS permissions. The app stores language preference, guest display name, completed cases and an anonymous guest identifier on this device to restore your interface and room experience.

Multiplayer room data

When you create or join a room, the anonymous guest identifier, display name, locale, membership relationship and game events you actively create—phase changes, evidence, questions and votes—are sent to the Nocturne service to synchronize the same room. Script content is not deleted when guest data is removed.

Service providers and country detection

The production service is hosted on Vercel, while room and script data are stored in Neon PostgreSQL. On first launch, the app may read a country code supplied by the deployment edge so mainland China defaults to Chinese and other regions default to English. The app does not send your IP to a separate geolocation vendor. There are currently no ads or behavior-analytics SDKs.

Your choices and deletion

You can edit your display name in the profile panel, or use “Delete guest data” to remove local records and request deletion of the matching guest profile, membership records and game-event associations on the server. Rooms you created that have not ended will be closed. If the device is offline, local data is still removed first.

Contact

Before a store submission, the publisher must add the real operating entity, support email, retention period and governing-law details. The current project feedback channel is GitHub Issues.
